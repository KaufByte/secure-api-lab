# Secure REST API (Node.js & Express)

Цей проєкт є навчальним сервером REST API, розробленим на базі платформи **Node.js** та фреймворку **Express**. Основне призначення додатку — демонстрація принципів побудови архітектури REST, обробки HTTP-запитів і кодів відповідей, ведення журналу подій (логування), а також впровадження механізмів безпеки (аутентифікації та рольової авторизації) за допомогою проміжних обробників (*middleware*).

Сервер надає доступ до двох типів ресурсів: документів (`/documents`), доступних для всіх аутентифікованих користувачів, та конфіденційних даних співробітників (`/employees`), доступних виключно користувачам з роллю адміністратора (`admin`). Аутентифікація реалізована через передачу облікових даних у кастомних HTTP-заголовках `X-Login` та `X-Password`.
